### ⚠️ **今後の絶対厳守事項**

#### 1. rsyncコマンド使用時のルール

**❌ 絶対にやってはいけないこと:**
```bash
# themes ディレクトリ全体に --delete を使用
rsync -avz --delete ... /themes/
```

**✅ 正しい方法:**
```bash
# 必ず swell_child ディレクトリを明示
rsync -avz -e ssh --exclude ".DS_Store" --exclude "*.bak" \
  swell_child/ \
  patolaqshe@www3521.sakura.ne.jp:/home/patolaqshe/www/media/wp-content/themes/swell_child/
```

#### 2. --deleteオプションの使用禁止
- `rsync --delete` は**原則使用しない**
- やむを得ず使用する場合は、送信元と送信先のパスを3回確認
- 親テーマ`swell`には一切触れない

#### 3. ファイル削除前の確認
- `rm -rf` コマンドを実行する前に、対象ディレクトリを必ず確認

### 📝 教訓

1. **rsync --delete は非常に危険**
   - 送信先に存在するが送信元に存在しないファイルは全て削除される
   - themesディレクトリ全体を対象にすると、親テーマも削除される

2. **バックアップの重要性**
   - updraftバックアップがあったため復旧可能だった
   - 定期的なバックアップは必須

3. **コマンド実行前の確認**
   - パスの確認（送信元/送信先）
   - オプションの確認（--deleteの有無）
   - 影響範囲の確認（親テーマが含まれないか）
